# Pretrained Models Directory
Store downloaded model weights here:
- Depth Anything V2 weights: `depth_anything_v2_vits.pth`
- MiDaS weights: `dpt_swin2_large_384.pt` or `midas_v21_small-70d6b9e8.pt`
- ZoeDepth weights: `ZoeD_M12_N.pt`

When running in an environment without pre-downloaded weights, the system automatically uses the built-in structural monocular depth estimator.
